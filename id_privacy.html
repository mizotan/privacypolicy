KEBIJAKAN PRIVASI (Indonesia)

Bonsai Project ("kami") menetapkan Kebijakan Privasi ini mengenai penanganan informasi pengguna dalam aplikasi kami ("Aplikasi").

1. Pengumpulan Informasi dan Tujuan

  • Pengidentifikasi Perangkat: Layanan iklan pihak ketiga (seperti Google AdMob) dapat secara otomatis mengumpulkan ID iklan (misalnya, AAID) untuk menampilkan iklan yang dipersonalisasi. Data ini tidak mengidentifikasi Anda secara pribadi.
  • Izin Kamera dan Mikrofon: Digunakan semata-mata untuk analisis video dalam aplikasi, efek khusus, dan perekaman. Semua data diproses secara lokal di perangkat Anda dan tidak pernah diunggah ke server kami.

2. Berbagi, Enkripsi, dan Penghapusan Data

  • Berbagi dengan Pihak Ketiga: Kami tidak membagikan data pribadi dengan pihak ketiga, kecuali diwajibkan oleh hukum.
  • Keamanan Data: Data yang dikirimkan melalui SDK iklan dienkripsi dalam transit menggunakan protokol aman (HTTPS).
  • Penghapusan Data: Aplikasi tidak memerlukan pendaftaran akun dan tidak menyimpan data pengguna di server kami. File media di perangkat dapat dihapus oleh pengguna kapan saja.

3. Penafian

Kami tidak bertanggung jawab atas kerugian yang timbul dari penggunaan Aplikasi ini. Aplikasi ini disediakan murni untuk tujuan hiburan.
