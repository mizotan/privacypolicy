KEBIJAKAN PRIVASI (Bahasa Indonesia)

Bonsai Project / 盆栽企画 ("kami") menetapkan Kebijakan Privasi ini terkait penanganan informasi pengguna di seluruh aplikasi ("Aplikasi") yang dikembangkan dan disediakan oleh kami. (Untuk daftar spesifik aplikasi yang tercakup, silakan lihat halaman utama).

1. Pengumpulan Informasi dan Tujuan

  • Pengidentifikasi Perangkat (Aplikasi dengan Iklan): Pada Aplikasi yang menampilkan iklan, layanan periklanan pihak ketiga (seperti Google AdMob) dapat secara otomatis mengumpulkan ID iklan (misalnya, AAID) untuk menyajikan iklan yang dipersonalisasi dan mengukur kinerja. Data ini tidak mengidentifikasi Anda secara pribadi.
  • Izin Kamera dan Mikrofon (Hanya Aplikasi Terkait): Pada Aplikasi yang menyertakan fitur kamera atau mikrofon, izin ini digunakan semata-mata untuk analisis video di dalam aplikasi, efek khusus, dan perekaman. Aplikasi yang tidak memerlukan fitur ini tidak mengakses kamera atau mikrofon Anda. Semua data diproses secara lokal di perangkat Anda dan tidak pernah diunggah ke server kami.

2. Pembagian, Enkripsi, dan Penghapusan Data

  • Pembagian dengan Pihak Ketiga: Kami tidak membagikan data pribadi kepada pihak ketiga, kecuali jika diwajibkan oleh hukum.
  • Keamanan Data: Data yang dikirimkan melalui SDK iklan dienkripsi selama transmisi menggunakan protokol aman (HTTPS).
  • Penghapusan Data: Aplikasi kami tidak memerlukan pendaftaran akun dan tidak menyimpan data pengguna apa pun di server kami. File media atau data aplikasi di perangkat dapat dikelola dan dihapus oleh pengguna kapan saja.

3. Penafian

Kami tidak bertanggung jawab atas segala kerugian atau kerusakan yang mungkin timbul dari penggunaan Aplikasi kami. Semua Aplikasi disediakan murni untuk tujuan hiburan.
